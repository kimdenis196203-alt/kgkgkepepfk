# Сверка Android-приложения с исходником Figma Make

## Источник
Архив «Личный кабинет успеваемости студента.zip», выгруженный из Figma Make.

## Состав исходного проекта
- Next.js 16, React 19, TypeScript.
- Основной экран и клиентская логика: `src/app/(frontend)/student-dashboard.tsx`.
- Загрузка данных: `src/app/(frontend)/page.tsx`.
- Серверные операции: `src/app/(frontend)/actions.ts`.
- Стили: `src/app/(frontend)/styles.css`.
- Payload CMS collections: Disciplines, Grades, Admins, Folders, Media, Tags.
- Отдельного каталога изображений интерфейса в архиве нет; визуальный слой реализован CSS и SVG-иконками.

## Экранная структура
1. HomeScreen — обзор, средний балл, счётчики, дисциплины.
2. GradesScreen — журнал, фильтры по дисциплине/типу/периоду, сортировка по дате и значению.
3. DisciplineScreen — карточка дисциплины, средний балл и история.
4. DynamicScreen — график динамики и калькулятор целевого среднего балла.
5. GradeModal — создание/редактирование оценки и подтверждение удаления.
6. BottomNav — нижняя навигация.

## Модель данных
Discipline: id, name, teacher, code, accent.
Grade: id, disciplineId, value (2..5), date, workType (control/practice/laboratory/answer/exam/other), comment (до 500 символов).

## Архитектурное отличие
Исходник использует Payload CMS и Next.js Server Actions. Android-проект использует локальную Room DB. В этом переносе сохраняется Room; Payload API не переносится автоматически, так как требует адреса развёрнутого backend и правил авторизации.

## Выявленные пробелы относительно веб-версии
- нет фильтров и сортировки журнала;
- нет полноценного редактирования и удаления оценок в UI;
- не реализован калькулятор целевого среднего балла (добавлен в Sprint 4);
- отсутствует управление дисциплинами;
- набор типов работы в форме добавления неполный;
- профиль/настройки не реализованы.

## Ограничения проверки
Android Gradle build в этой среде не запускался; успешная компиляция не подтверждена.

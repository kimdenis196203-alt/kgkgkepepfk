# Отчёт по спринту 3 — перенос макета Figma в Android

**Проект:** «Личный кабинет успеваемости студента»  
**Ведущая роль: LD (Lead Designer).** Ответственность спринта — визуальная структура, согласованность экранов и перенос дизайн-решений Figma в Android-интерфейс. Реализация Compose-компонентов сопровождала эту работу.

## Цель
Перенести визуальную систему основного макета Figma в Android-приложение на Kotlin с использованием Jetpack Compose и обеспечить целостность пользовательского интерфейса.

## Выполненные работы
1. Определена и перенесена визуальная система: тёплый светлый фон, тёмно-зелёные карточки, лаймовые акценты, скруглённые поверхности и компактные подписи.
2. Сформирована структура главной сводки, списка дисциплин, журнала оценок и аналитики.
3. Реализована нижняя навигация между разделами.
4. Подготовлены состояния просмотра дисциплины и списка оценок.
5. Согласованы элементы формы добавления оценки с визуальным языком приложения.
6. Compose-компоненты подключены к существующему StudentRepository для отображения актуальных данных.

## Результат
Основные разделы получили единый визуальный стиль, основанный на исходном макете Figma. Интерфейс перенесён в Jetpack Compose; это не пиксель-в-пиксель копия всех состояний Figma Make.

## Ограничения и проверка
- В текущей версии доступны просмотр и добавление оценок; редактирование/удаление оценок и управление дисциплинами в UI ещё не реализованы.
- Сборка Gradle и запуск на Android-эмуляторе в рамках этого изменения не выполнялись, поэтому успешная компиляция пока не подтверждена.

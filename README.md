# Личный кабинет успеваемости студента

Мобильное Android-приложение для просмотра учебных оценок, группировки по дисциплинам и контроля успеваемости.

## Реализация
- [Спринт 1 — требования, сценарии и прототип интерфейса](docs/SPRINT_1.md)
- [Спринт 2 — модель данных и локальное хранение](docs/SPRINT_2.md)

## Технологии
- Kotlin
- Android Gradle Plugin
- Room / SQLite
- Kotlin Coroutines + Flow
- KSP

## Командные роли
| Роль | Ответственность |
|---|---|
| Product Owner / аналитик | Требования, сценарии, критерии приёмки, согласование результата |
| Lead Developer | Архитектура, Kotlin, модель данных, интеграция |
| QA / DevOps | Тест-кейсы, проверка CRUD и сохранения, контроль сборки |

Распределение ролей является планом команды; конкретные GitHub-аккаунты участников не назначены.

## Сборка
Откройте проект в Android Studio с установленным Android SDK 35. После синхронизации Gradle запустите конфигурацию `:app` на эмуляторе или устройстве.

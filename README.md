# Личный кабинет успеваемости студента

Мобильное Android-приложение для просмотра учебных оценок, группировки по дисциплинам и контроля успеваемости.

## Технологии
- Kotlin
- Android Gradle Plugin
- Room / SQLite
- Kotlin Coroutines + Flow
- KSP

## Командные роли
| Роль | Ответственность |
|---|---|
| PO (Product Owner) | Требования, сценарии, критерии приёмки, согласование результата |
| LD (Lead Developer) | Архитектура, технические решения и интеграция |
| Dev | Реализация функций и тестов |

Роли указаны по зонам ответственности; конкретные GitHub-аккаунты участников не назначены.

## Сборка
Откройте проект в Android Studio с установленным Android SDK 35. После синхронизации Gradle запустите конфигурацию `:app` на эмуляторе или устройстве.

Проверка тестов:
- Unit-тесты: `./gradlew test`
- Instrumentation-тесты: `./gradlew connectedAndroidTest` (требуется запущенный эмулятор или подключённое устройство).
